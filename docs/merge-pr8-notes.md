## Decisions taken before resolving (by the team lead)

PR #8 and this branch each built a device-claiming system, and the two designs conflict. Three decisions settled it:

1. **Claim path: ours.** The `claimDevice` Cloud Function with organizations (`docs/access-model.md`) is the path the app uses. Gian's route is kept in the repo as reference and is not wired into the UI.
2. **Claim proof: the claim code stays required.** Knowing a device ID alone is not enough to claim it; the user also needs the 8-character code on the label. Gian's design was ID-only, first-eligible-account.
3. **Firebase plan: Blaze with Cloud Functions.** Sprints 1–4 run as Cloud Functions: the ingest pipeline, alerts, notifications, the command log, scheduled checks and claiming. Gian's design assumed the free Spark plan, with claiming as a Next.js route on Vercel.

## Kept from PR #8 (in use)

- **Firmware:** `firmware/Aquarium1Device`, `firmware/Aquarium2Device` and `firmware/README.md`.
  - UTC+8 schedules, feeder timing, echo-median water level, and the power-presence detector.
  - Static checks: `npm run test:firmware-contract`.
- **Telemetry fields** `lightState` (On/Off) and `turbidityState` (Clear/Cloudy/Unknown), with their RTDB validation. These are additive.
  - The app shows the light and filter state the device reports (`getReportedManualStatus`).
  - Turbidity shows the Clear/Cloudy category when the device sends one; a numeric NTU value is never invented.
- **Monitoring:**
  - The browser telemetry simulator is removed (live data only, per AGENTS.md §22).
  - Manual controls work while automation is on.
  - Water level shows one decimal place.
- **Schedule editor:** checks HH:MM format and that light on ≠ light off, together with our 30-minute feeding gap.
- **`.gitignore`:** private firmware identities, device logins, admin keys and firmware build output.
- **Docs:** `docs/security/aquarium1-live-setup-status.md`, `aquarium2-live-setup-status.md` and `review-handoff-2026-11-07.md`. These record the hardware work and what is live.
- **Tests:** RTDB rule tests (2 new), `test:device-claim-unit`, `test:claim-origin`, `test:aquarium2-firmware`.
